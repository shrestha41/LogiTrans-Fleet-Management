# LogiTrans Fleet Management Prototype
Object-oriented Python prototype demonstrating abstraction, encapsulation, inheritance and polymorphism.

| File | Purpose |
|---|---|
| `fleet_management.ipynb` | Jupyter notebook with explanations, code and outputs (run all cells) |
| `fleet.py` | Plain script: `Vehicle` (abstract), `PassengerCar`, `CargoTruck`, `generate_fleet_manifest()` |
| `test_fleet.py` | 23 unit tests |

Run: `python fleet.py` and `python test_fleet.py` (Python 3.8+, no dependencies).
Keep the notebook in the same folder as the two `.py` files; its last cell runs the tests.
